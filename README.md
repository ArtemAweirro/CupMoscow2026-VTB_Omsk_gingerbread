# Cup Moscow 2026 · ВТБ «Деньги под защитой» · «Омский пряник»

Excel-модель экономики и KPI + Python-симуляция вариантов В1–В4. **Иллюстрация механизма, не прогноз.**

## Структура
| Путь | Что |
|---|---|
| `model/CupMoscow2026-ВТБ-ОмскийПряник.xlsx` | Excel-модель: 11 листов, все входы на листе «Допущения», 906 формул |
| `model/build_model.py` | Сборка Excel (структура, формулы, источники) |
| `model/check_model.py` | Пересчет без Excel: ошибки, «зашитые» числа, сверка с `00`; пишет `out/model_values.json` |
| `sim/simulate.py` | Генератор синтетических данных и сравнение В1–В4 |
| `sim/charts.py` | Графики PNG (220 dpi) и CSV в `out/` |
| `out/01…05_*.png` | Графики для слайдов 3, 6, 7 |
| `out/*.csv` | Данные графиков и таблиц |
| `docs/Приложение_симуляция.md` | Текст слайда-приложения о симуляции |
| `docs/Вопросы_аналитику.md` | Расхождения с открытыми данными и вопросы до заморозки |
| `docs/00_…`, `docs/02_…` | Исходные решения и инструкция команды |
| `deck/build_deck.py`, `deck/style.css` | Презентация (Разработчик 2): HTML-слайды из цифр модели → PDF через Chrome |
| `deck/CupMoscow2026-ВТБ-ОмскийПряник.pdf` | Итоговый PDF: 8 слайдов + 8 приложений |

## Запуск
```sh
./run_all.sh   # симуляция → Excel → проверка → графики → презентация
.venv/bin/python deck/build_deck.py   # только презентация (нужны openpyxl и Google Chrome)
```
Окружение: `.venv` (Python 3.11, numpy, pandas, scikit-learn, openpyxl, matplotlib, formulas).

## Ключевые цифры
- **Потери клиентов ВТБ в фокусе:** 1 964 → 1 571 млн руб./год. Сохранено 393 млн: это KPI клиента, не доход банка.
- **Корректно выявлено мошеннических операций (KPI б, по числу):** 341 → 358 тыс./год (+5%; пессимист 350, оптимист 356 при −3% попыток). Допущение: полнота по числу = полнота по сумме.
- **Ошибочные ограничения:** 0,525% → 0,216% законных переводов, −59%.
- **NPS:** +0,79 п.
- **Эффект для банка:** 273 млн руб./год, из них избежанный расход 59, экономия на ограничениях 128, удержание 86. За вычетом эксплуатации (24) чистый эффект 249 млн руб./год.
- **Внедрение:** 47,6 млн руб. (≤ 50), 6 мес. Окупаемость на 8-м месяце от старта (пессимист: 16-й). Накопленный эффект за 36 мес.: 584 млн руб.
- **Симуляция при равном трении:** непредотвращенные потери В3 27%, В4 38%, В2 39%, В1 46%.
